# life-better

> 生活经验库 · 微信小程序
> 一条经验 = 结论 + 可判定立场的要点 + 挂在要点上的依据来源 —— 可检索、可溯源、可反馈。

**当前状态**：设计已确认，**前端高保真原型已完成**（14 个页面都能点）；
后端与小程序端尚未开工。

## 已经做完的

- **设计**：产品定位、内容模型（经验 / 要点 / 依据三层）、数据模型、搜索方案（向量 + 关键词 RRF 融合）、API 清单、上线合规门槛 —— 都在设计文档里
- **视觉方向**：定稿为**便签墙**；另外两套方向已删，否掉的理由留档在 [`design/README.md`](design/README.md) §5
- **原型**：14 个页面全部可点 —— 首页 / 领域 / 搜索 / 详情 / 依据来源 / 我的 / 收藏夹 / 反馈提交 / 我的反馈 / 管理 4 页 / 关于与隐私
- **可切换的演示态**：两种身份（管理员 / 普通用户）× **十种**数据场景（默认 / 仅语义 / 关键词降级 / 演示数据 / 空状态 / 存在争议 / 加载中 / 检索超时 / 未登录 / 网络失败）
- **演示数据**：32 条经验（30 已发布 + 2 草稿）/ 9 领域 / 38 标签 / 91 要点 / 62 条依据 / 7 条反馈；统计数字全部由数据派生，不写死
- **第三轮审查落地**：39 条问题逐条核对后**全部真实存在**，已在原型与设计文档里改完 ——
  改了哪些地方见设计文档 [§19 第 6 轮](docs/better-life-design.md)
- **自检**：`node scripts/verify-prototype.mjs` → 174 项断言全绿（含 CSS 对比度实时复算）
