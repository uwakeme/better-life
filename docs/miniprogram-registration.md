## 2. 小程序介绍（99 字）

> Wake日子有方：一个生活经验检索库。每条经验先给结论，再给要点，每条要点都标注来源链接，可检索、可溯源。覆盖购物、吃喝、健康、钱财等九个领域，内容由维护者逐条录入，仅收录通用经验，不替代专业建议。

首句带名称是给审核看的：**名称 / 简介 / 类目 / 实际页面**四处能直接互相对上。
文案避开了绝对化用语与疗效承诺，也避开了投稿、社区、共享字样；「内容由维护者逐条录入」
对应**反馈仅管理员可见**的既定决策，避免被判为 UGC。

## 3. 填表前必须自查的两点（只能本人查）

1. **「Wake」商标**
   北京唤醒之光网络科技有限公司已在大健康 / 生活服务类目运营「Wake健康大使中心」「Wake约课馆主版」，
   另有个人主体小程序「WakeUper」（健康管理教育信息服务）。
   → 商标网 <https://sbj.cnipa.gov.cn> 按**文字商标 = Wake**、分类 **42（软件）/ 45（信息检索）** 查在先注册；
   若对方在同类服务上已实际使用，建议换掉英文前缀。

2. **中文部分的近似名**
   已上线的小程序「**今日有方**」（观猹，watcha.cn/products/2726）是同赛道的东方生活方式生活指引小程序，
   与「日子有方」仅一字之差；另有已启幕品牌「**日日有方**」（AI 草本饮，2026 上线）。
   → 微信名称审核会驳回与已有小程序**近似**的名字。Wake 前缀已拉开区分度（读音、结构、视觉均不同），
   但仍可能被要求改名，而**改名次数有限**。

   若被驳回，同族微调（字数与简称均已核对）：

## 5. 类目与备案（不在表单里，但影响过审）

- **服务类目**：工具-信息查询，个人主体即可。
  前提是保持「反馈仅管理员可见」—— 一旦公开可见就落入社交类目，个人主体不开放，需换企业主体 + ICP 备案 + 网信审核。
- **服务器域名**：`better-life.uwakeme.top` 必须已完成 ICP 备案，否则合法域名配不上去，`wx.request` 调不通，审核时接口是空的。
- **小程序备案**：与域名 ICP 备案是两件事，都要办；工信部核验短信（12381）要在时限内回复。
- **修改额度**：名称与头像一年内可改次数有限（官方口径为企业类型 1 次，个人主体同量级或更少）—— 一次定死。
